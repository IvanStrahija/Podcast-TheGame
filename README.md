## 🎙️ About the Project

This repository contains a **web-based implementation** of the board game *Podcast – The Game*.

The goal of this project is to recreate the core gameplay experience in a **digital format**, optimized for tablet devices (especially iPad), allowing players to enjoy the game through a browser.

---

## 🎯 Purpose

* Practice front-end development using **HTML, CSS, and JavaScript**
* Explore digital adaptations of physical board games
* Create a fun, local multiplayer experience for friends
